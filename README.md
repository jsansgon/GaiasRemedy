# Gaia's Remedy

Prototip 2D d’exploració desenvolupat amb Unity per al Treball de Fi de Grau.

## Descripció

Acompanya la Gaia mentre explora casa seva, el carrer i el bosc. En aquesta versió es poden recórrer les escenes, controlar la protagonista, veure com transcórre el temps del joc i recollir una planta sagrada al bosc.

## Controls

- **WASD** o **fletxes**: moure la Gaia
- **E**: interactuar i recollir la planta
- **Esc**: obrir o tancar el menú de pausa

## Executar el joc

Descarrega la versió corresponent al teu sistema operatiu des de **Releases**:

- **Windows**: descomprimeix el ZIP i executa `GaiasRemedy.exe`.
- **macOS**: descomprimeix el ZIP i obre `GaiasRemedy.app`.

## Estat del projecte

Prototip acadèmic en desenvolupament. Les mecàniques i els continguts evolucionaran en versions posteriors.
